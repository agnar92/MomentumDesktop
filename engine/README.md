# engine/

`watchlist.py` i `finviz.py` to **niezmieniona kopia** silnika z repozytorium Momentum (Finviz → yfinance → RS / EPS Rating /
bazy / wykresy tygodniowe → JSON). Dzięki temu logika i strategia są dokładnie te same co w wersji na GitHub Pages.

Aktualizacja do nowszej wersji Momentum: skopiuj oba pliki z Momentum nad te tutaj (`cp ../Momentum/{watchlist,finviz}.py engine/`).
Nie edytuj ich tutaj — zmiany w obliczeniach rób w Momentum.
