# CEM10

Program na Windows do strategii CEM10: lista miesięczna USA / GPW, portfel z raportu XTB, plan wpłaty i krzywa kapitału.
Opis reguł i obsługi: [CEM10.md](CEM10.md). Uruchomienie ze źródeł: `pip install -r requirements.txt` i `python cem10_main.py`
(`--browser` = w przeglądarce zamiast w oknie). Testy: `python -m pytest -q && ruff check .`.
